# PartTimeBeat 금칙어 목록 — 형식 예시 파일
#
# ※ 실제 금칙어 목록은 ForbiddenWords.txt에 작성합니다.
#   ForbiddenWords.txt는 .gitignore에 등록되어 저장소에 올라가지 않습니다.
#   이 파일(ForbiddenWords.example.txt)을 복사해 ForbiddenWords.txt로 이름을 바꾼 뒤
#   아래 형식에 맞게 금칙어를 채워 사용하세요.
#
# ── 형식 규칙 ──────────────────────────────────────────────────────
#   - 한 줄에 단어 하나
#   - '#'으로 시작하는 줄은 주석 (무시됨)
#   - 빈 줄은 무시됨
#   - 한글은 음절(시발) 또는 자모 약어(ㅅㅂ) 형태로 입력
#   - 영어는 소문자로 입력 (대소문자 구분 없이 검사됨)
#
# ── 정규화 동작 ────────────────────────────────────────────────────
#   검사 시 아래 두 경로를 동시에 적용합니다:
#   1) 혼합 정규화  : 한글 자모 분해 + 영숫자 소문자 유지 + 특수문자 제거
#      → "시×발", "f*ck", "ㅅ ㅣ ㅂ ㅏ ㄹ" 우회 차단
#   2) 한글 전용 정규화 : 한글 자모만 추출, 영숫자 포함 나머지 제거
#      → "ㅅxㅂ", "ㅅ1ㅂ" 우회 차단
#
# ── 작성 예시 ──────────────────────────────────────────────────────
# 한국어 (음절형)
# 예시단어
#
# 한국어 (자모 약어형)
# ㅇㅇ
#
